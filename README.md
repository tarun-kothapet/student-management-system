Student Management System

A web-based Student Management System developed using Spring Boot,
Spring MVC, Spring Data JPA, Hibernate, Thymeleaf and MySQL.

Features
• Add Student
• View Students
• Update Student
• Delete Student
• Store data in MySQL Database
• Simple and Responsive User Interface

Technologies
• Java
• Spring Boot
• Spring MVC
• Spring Data JPA
• Hibernate
• Thymeleaf
• HTML
• CSS
• Bootstrap
• MySQL
• Maven
• Eclipse / Spring Tools Suite (STS)

Project Architecture
This project follows the MVC (Model-View-Controller) architecture.

• Model – Student Entity and Database
• View – Thymeleaf Templates
• Controller – Handles HTTP Requests
• Repository – Database Operations using Spring Data JPA
